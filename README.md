# 📚 Amazon Best-Selling Books Dashboard

[![Streamlit App] https://amazon-books-analyzer-5fftiykkftzbe2ugyqmx4e.streamlit.app/

An interactive data analytics dashboard exploring historical bestselling books data from Amazon (2009–2019). Built using Python, Pandas, Plotly Express, and Streamlit.

## 🚀 Live Demo
Check out the live interactive application here: **[Amazon Books Analyzer](https://amazon-books-analyzer-5fftiykkftzbe2ugyqmx4e.streamlit.app/)

## 📊 Key Features
- **Executive KPI Overview**: Tracks total catalog size, average rating, price baselines, and review engagement with live delta comparison cards.
- **Sub-Genre Classification**: Custom keyword-matching algorithm categorizing books into targeted sub-genres (Finance, Self-Help, Thrillers, YA, etc.).
- **Interactive Multi-Variable Filters**: Filter in real-time by main genre, publication year range, and maximum price threshold.
- **Dynamic Visual Analytics**: Plotly bar and line charts analyzing year-over-year genre distribution and pricing trajectories.
- **Filtered Data Export**: Download customized dataset subsets directly as CSV files.

## 🛠️ Tech Stack
- **Language**: Python
- **Data Manipulation**: Pandas
- **Interactive Visualizations**: Plotly Express
- **Web Framework**: Streamlit
